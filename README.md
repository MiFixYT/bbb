🧩 Block Blast Boost

Умный помощник для Block Blast на Android.

Block Blast Boost помогает анализировать игровое поле и подбирать лучшие ходы.

✨ Возможности

- 🔍 Сканирование игрового поля.
- 💡 Расчёт подсказок для размещения фигур.
- 🧩 Ручной редактор фигур.
- 📱 Плавающее окно поверх игры.
- 🎨 Тёмный интерфейс с розовыми акцентами.
- 🗂️ Три отдельных слота для фигур.

🧩 Редактор фигур

Нажми кнопку «Фигуры», чтобы открыть полноэкранный редактор.

- Три вкладки: Фигура 1, Фигура 2, Фигура 3.
- Сетка 3×3 для каждой фигуры.
- Нажатие на клетку включает или выключает её.
- Кнопка «Очистить» сбрасывает текущую фигуру.
- Кнопка «Готово» возвращает к игровому окну.

📱 Требования

- Android 8.0 или новее.
- Разрешение на отображение поверх других приложений.
- Служба специальных возможностей для поддерживаемых функций.

🚧 Статус проекта

Проект находится в разработке.

Некоторые функции могут работать нестабильно. APK и совместимость с разными устройствами требуют тестирования.

🎯 Цель проекта

Создать удобного помощника Block Blast, который позволит быстро анализировать поле, вручную задавать фигуры и получать полезные подсказки.
